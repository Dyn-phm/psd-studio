# PSD Studio Flat — Trình đọc, Phân tích & Chỉnh sửa File Photoshop (.PSD) Online / Local

Ứng dụng web (HTML5/JS) chạy trực tiếp trên trình duyệt giúp đọc, phân tích cấu trúc và chỉnh sửa file **Adobe Photoshop (`.psd`)**, **Smart Object**, **Font Text**, **Layer Effects (FX)** và xuất ra **`.PNG`**, **`.JPG`**, hoặc lưu lại file **`.PSD`**.

## Tính năng nổi bật
- **Đọc đầy đủ cấu trúc PSD**: Layer ảnh (Pixel), Thư mục (Group đa cấp), Smart Object (`placedLayer` & `linkedFiles`), Text Layer (`TySh`), Vector/Shape, Layer Mask (`🎭Mask`) và Clipping Mask (`⤵Clip`).
- **Bảo toàn 100% Font chữ & Hiệu ứng gốc**:
  - Giữ nguyên bitmap chữ và hiệu ứng đã được Photoshop render sẵn.
  - Hỗ trợ nạp thêm file Font (`.TTF`, `.OTF`, `.WOFF`) trực tiếp từ thiết bị và tích hợp sẵn các bộ Google Fonts Tiếng Việt (*Be Vietnam Pro, Montserrat, Roboto, Inter, Oswald, Anton, Playfair Display*).
- **Chỉnh sửa trực tiếp**:
  - Ẩn/hiện, xóa Layer, nhân bản Layer, đổi thứ tự Layer, hoàn tác (`Ctrl+Z`).
  - Thay thế nội dung Layer / Smart Object bằng ảnh `.JPG`, `.PNG`, `.WEBP` (4 chế độ khớp khung: *Contain, Cover, Stretch, Original*).
  - Bật/tắt và tùy chỉnh hiệu ứng **Drop Shadow (Bóng đổ)**, **Stroke (Viền đối tượng)**, **Outline chữ**.
- **Giao diện Flat Design & Responsive**:
  - Chế độ Sáng / Tối (*Light / Dark Flat UI*).
  - Tương thích hoàn toàn với **Desktop, Tablet và Mobile** (hỗ trợ cảm ứng chạm chọn Layer, kéo di chuyển Layer và chụm 2 ngón *Pinch-to-Zoom*).
- **Xuất file**: Xuất ảnh `.PNG` (trong suốt), `.JPG` (tùy chỉnh chất lượng), tải riêng từng Layer hoặc lưu lại thành file `.PSD`.
